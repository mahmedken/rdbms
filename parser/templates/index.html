SQL Command Reference

SELECT Syntax 
SELECT column1, column2, ... FROM table_name [WHERE condition]

Used to retrieve data from one or more tables.

CREATE TABLE Syntax 
CREATE TABLE table_name (column1 type1, column2 type2, ...)

Creates a new table with the specified columns and data types.

DROP TABLE Syntax 
DROP TABLE table_name

Removes a table and all its data from the database.

CREATE INDEX Syntax 
CREATE INDEX table_name column_name

Creates an index on a column to speed up queries.

DROP INDEX Syntax 
DROP INDEX table_name column_name

Removes an index from a column.

INSERT Syntax 
INSERT INTO table_name (column1, column2, ...)
        VALUES (value1, value2, ...)

Inserts a new row into a table.

UPDATE Syntax 
UPDATE table_name
        SET column1 = value1, column2 = value2, ...
        [WHERE condition]

Modifies existing rows in a table.

DELETE Syntax 
DELETE FROM table_name
        [WHERE condition]

Removes rows from a table.
